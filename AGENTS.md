# Running Tracker

This is a standalone React app deployed to GitHub Pages. The original Hatch
builder instructions no longer apply to this migrated copy.

- Use `npm install`, `npm run dev`, and `npm run build`.
- Google Sheets is the only durable run database. Do not persist runs locally.
- Preserve the playful visual design and interactive public street map.
- Distinguish challenge milestones from estimated road distances.
- Do not test writes against the owner’s live sheet. Use a mocked API.
